## 1. What Can Claude Cowork Do?

### The Core Idea

Claude Cowork turns Claude from a chatbot into a hands-on digital coworker. Instead of just answering questions, it reads, edits, and creates real files on your computer — spreadsheets, presentations, documents, organized folders — and completes multi-step tasks end to end. You describe the outcome you want, Claude plans and executes it, and you steer along the way.

### Key Capabilities

- **Direct file access** — reads and writes to your local folders without manual uploads or downloads
- **Multi-step task execution** — breaks complex jobs into sub-tasks and runs them in parallel
- **Professional deliverables** — produces Excel files with working formulas, PowerPoint decks, formatted reports
- **File organization** — rename, sort, deduplicate, and restructure messy folders
- **Research synthesis** — pulls info from multiple sources and assembles structured outputs
- **Browser automation** — connects to Chrome for web research and form filling
- **Scheduled tasks** — set recurring work (e.g., weekly metric pulls, daily email digests)
- **App connectors** — integrates with Google Drive, Gmail, Slack, DocuSign, HubSpot, and 200+ apps
- **Plugins & skills** — install pre-built workflows for finance, legal, marketing, HR, and more

### How It Differs from Regular Claude Chat

Regular Claude is a conversation — you ask, it answers. Cowork is a working session — you describe the outcome, and Claude plans, executes, and delivers finished work. As Anthropic puts it: "It feels much less like a back-and-forth and much more like leaving messages for a coworker."

### Prerequisites

- A paid Claude plan (Pro at $20/mo, Max, Team, or Enterprise)
- Claude Desktop app installed (macOS or Windows)
- Latest version — download from [claude.com/download](https://claude.com/download)

### Quick Starter Tasks

1. Point Cowork at your **Downloads folder** and ask it to organize, rename, and deduplicate files
2. Give it a set of **meeting notes** and ask for a structured summary document
3. Hand it scattered data and ask for an **Excel spreadsheet with charts**
4. Ask it to turn rough notes into a **polished PowerPoint presentation**
5. Set up a **recurring task** — e.g., pull metrics every Monday morning
6. Connect **Chrome** and have it research a topic across multiple websites

### Pro Tips

- Start with a **dedicated work folder** — don't point Claude at your entire Documents directory on day one
- Always be explicit: say "don't delete anything" unless you specifically want deletions
- Back up important files before letting Cowork modify them
- Write outcome-focused prompts — describe what "done" looks like, not the steps

## 9. Cowork Features at a Glance

A reference guide to each major Cowork feature and what it does.

### Skills

Skills are reusable sets of instructions that teach Claude how to perform a specific task. Think of them as saved recipes — you define the steps once, and then invoke them whenever you need that workflow again. You can create your own or install pre-built ones. Examples include a skill for applying consistent branding to visuals, formatting expense reports, or generating SEO-optimized blog drafts. Invoke them with slash commands (e.g., `/my-skill-name`).

### Plugins

Plugins bundle multiple skills, connectors, and sub-agents into a single installable package. Where a skill handles one task, a plugin handles an entire domain. Anthropic ships official plugins for areas like legal (contract review, NDA triage), finance (forecasting, expense tracking), sales (pipeline review), and marketing. You can also customize them — for instance, telling the legal plugin to apply Singapore law instead of US law. Find them under Settings > Customize.

### Connectors

Connectors link Cowork to external apps you already use — Gmail, Google Drive, Slack, Notion, HubSpot, Figma, Microsoft 365, and over 200 others as of May 2026. They let Claude read emails, access shared documents, sync calendars, and update CRM records without you switching windows. For tools not in the connector directory, you can set up custom connections using MCP (Model Context Protocol).

### Projects

Projects are persistent, self-contained workspaces inside Cowork. Each project has its own files, links, instructions, and memory, so context doesn't bleed between different areas of work. If you're managing a client engagement, a research initiative, and a marketing campaign simultaneously, each gets its own project space. Claude remembers the project context across sessions.

### Scheduled Tasks

Scheduled tasks let you define a recurring job once and have Claude run it automatically — hourly, daily, weekly, or on a custom cadence. Type `/schedule` in any Cowork task to set one up. Your computer must be awake and the Claude app open for them to run. Common examples include morning email triage briefings, weekly expense reports, Friday file cleanup, and Monday metrics pulls.

### Routines (Research Preview)

Introduced in April 2026, Routines are a cloud-hosted automation tier that runs even when your laptop is closed — unlike Scheduled Tasks, which require your desktop to be on. Routines are currently in research preview and are distinct from the desktop-bound scheduled tasks.

### Sub-Agents

When Claude encounters a complex task, it can spin up multiple sub-agents that work in parallel. One might research competitors while another compiles findings into a summary. You don't have to manage this — Claude coordinates the sub-agents automatically and merges their outputs. This is what makes Cowork faster than doing things step by step.

### Live Artifacts

Live Artifacts are interactive, real-time visual outputs — dashboards, data tables, charts, or trackers — that Claude generates and updates within Cowork. They make complex data accessible at a glance. For example, you could ask Claude to build a project status dashboard that updates as files in your project folder change.

### Dispatch (Mobile Access)

Dispatch lets you message Cowork from your phone and have it execute tasks on your desktop. You text Claude a task, it runs the workflow on your computer using your local files and connectors, and you come back to finished files. Available for Pro and Max plans. You don't need to be sitting at your desk — just have the desktop app open.

### Claude in Chrome (Browser Automation)

This connector gives Cowork the ability to control a Chrome browser — navigate websites, fill forms, extract information, and perform web research. It's useful for tasks like pulling data from dashboards, downloading invoices, or conducting competitive research across multiple sites. It runs as a browser extension alongside the desktop app.

### Computer Use

Computer Use gives Claude direct control of your mouse and keyboard, allowing it to interact with any application on your desktop — not just files and Chrome. It takes screenshots to understand what's on screen and then performs actions. This is the most powerful (and most risk-aware) feature: useful for tasks that involve apps without a direct connector, but requires careful judgment about what you expose.

### Global vs. Folder Instructions

Global Instructions apply to every Cowork session regardless of which folder you're working in — your "always do this" rules (e.g., "never delete files without asking," "use this tone in documents"). Folder Instructions are specific to a single project folder and set context for that particular workspace. Together they let you customize Claude's behavior at both a general and project-specific level.

### Ideas Dashboard

A newer addition that provides pre-filled prompts and suggested connectors for common tasks. It helps you get started quickly by offering ready-to-use templates for things like email triage, content repurposing, expense tracking, and meeting prep — so you don't have to write prompts from scratch.

## 10. Creating HTML Prototypes with Cowork

One of the most practical — and underappreciated — uses of Cowork for IT analysts and managers is rapidly building interactive HTML prototypes. Instead of waiting weeks for a developer to mock something up, or struggling with design tools you don't know, you can describe what you want and get a working, clickable prototype in minutes.

### Why This Matters for IT Teams

Traditional prototyping requires either design tool expertise (Figma, Sketch) or developer time. Both are scarce. Cowork removes that bottleneck: you describe a screen, a workflow, or a dashboard concept in plain language, and Claude produces real HTML, CSS, and JavaScript — not a static image, but something people can actually click through. This is powerful for stakeholder demos, requirements gathering, vendor evaluations, and getting buy-in before committing development resources.

### What Cowork Can Produce

- **Wireframes** — low-fidelity, black-and-white layouts to explore ideas fast without getting bogged down in visual details
- **High-fidelity mockups** — polished, branded prototypes with real colors, fonts, and imagery that look like finished products
- **Interactive prototypes** — working tabs, navigation, form validation, hover states, accordions, and clickable flows
- **Dashboards** — data visualization layouts with placeholder charts, KPI cards, and filter controls
- **Multi-page sites** — linked pages with shared navigation for demonstrating full user journeys
- **Sketch-to-prototype** — upload a photo of a whiteboard sketch or hand-drawn wireframe and Claude will interpret it into a working HTML page

### How to Do It in Cowork

**Simple single-page prototype:** Open Cowork, point it at a project folder, and describe what you want. For example: *"Create an HTML prototype for an employee onboarding dashboard. Include a sidebar with navigation, a main area with progress cards for each onboarding step, and a header with the employee's name. Use a clean, modern style."* Claude will create the HTML, CSS, and JS files in your folder.

**Multi-page prototype:** For anything beyond a single page, Cowork and Claude Code are both strong choices. Describe the full set of pages and their relationships: *"Create a 4-page HTML prototype for our internal IT ticketing system: a ticket list page, a ticket detail page, a new ticket form, and a dashboard with metrics. Link them with shared navigation."* Cowork will scaffold the folder structure and generate all the files.

**Iterate by talking:** Once the first version is in your folder, you can refine it conversationally — *"Make the sidebar collapsible," "Add a dark mode toggle," "Replace the placeholder chart with a bar chart showing monthly tickets."* Claude edits the files in place.

### Sample Prompts for IT Analysts & Managers

| # | Scenario | Prompt Example |
|---|----------|----------------|
| 1 | Requirements demo | "Create an HTML prototype of our proposed vendor management portal. Show a vendor list with status badges, a detail page with contract info, and a comparison view side by side." |
| 2 | Process visualization | "Build an interactive HTML flowchart showing our current change management process. Make each step clickable to show details about approvals and SLAs." |
| 3 | Dashboard concept | "Prototype a CIO dashboard with cards for system uptime, open incidents, project status, and budget burn rate. Include a filter bar for date range." |
| 4 | Mobile-first layout | "Create a mobile-responsive HTML prototype for a field technician app. Include a job queue, job detail view with checklist, and a photo upload area." |
| 5 | Before/after comparison | "Build two versions of our help desk landing page — the current layout and my proposed redesign — side by side in a single HTML file with a toggle to switch between them." |

### Tools That Complement This Workflow

- **Claude Design** (launched April 2026) — Anthropic's dedicated design tool that produces clickable HTML prototypes with wireframe and high-fidelity modes, including a "Handoff to Claude Code" export for turning prototypes into real code
- **Wireframe skills** — installable skills from the MCP marketplace (e.g., wireframe-design, wireframing) that give Claude specialized UX design instructions
- **Claude in Chrome** — useful for screenshotting existing apps and asking Claude to recreate or improve them as prototypes
- **Netlify Drop** — a free way to publish your HTML prototype to a shareable URL with zero setup, great for stakeholder reviews

### When to Use What

| Need | Best Tool |
|------|-----------|
| Quick single-page concept | Claude Chat (artifacts) or Cowork |
| Multi-file prototype with shared navigation | Cowork or Claude Code |
| Polished visual prototype with design system | Claude Design |
| Production-ready code from a prototype | Claude Code (or Claude Design → handoff to Code) |

### The Bottom Line

You don't need to be a developer or designer to demonstrate what's possible. A well-prompted Cowork session can produce in 15 minutes what used to take days of back-and-forth between business and IT. For analysts and managers, this means you can walk into a meeting with something people can see and click — not just a slide with bullet points.
